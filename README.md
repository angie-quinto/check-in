# Check In

A small Android app for private, personal mood check-ins. Its only task is to offer a thoughtful moment of reflection—either from the app or straight from a notification.

## Privacy

The app has no account, analytics, or network access. It keeps your preferred name, reminder rhythm, reminder on/off setting, and check-in history (mood plus local date/time) only in Android's private on-device app storage. Nothing is uploaded. The person can view or permanently clear their history at any time.

## Use

1. On first launch, choose how the app should address you and a check-in rhythm—from every hour to once a day.
2. Allow notifications when Android asks.
3. Change your name or rhythm whenever you like from the app.
4. Each reminder has **I’m okay** and **Not really** actions, so a check-in never needs more than one tap.
5. Open **Recent check-ins** to see every saved mood with its date and time, or clear the on-device history.

Prompts are intentionally gentle and silent by default. Android may delay a prompt during battery-saving modes, then deliver the next available one.

## Build in Android Studio

Open this `CheckIn` folder in Android Studio, select an Android 8.0+ device or emulator, and run the `app` configuration. The project uses Android SDK 34 and Java 17.
